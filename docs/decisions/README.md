# 의사결정 기록 (ADR)

되돌리기 비싼 결정과 **그때 버린 대안**을 남기는 곳.
언제 쓰는지는 `CLAUDE.md` 「쓰기」 절의 ADR 트리거 참조.

> 여기엔 **판단만** 쓴다. 구현 방법·진행 상황은 쓰지 않는다.

## 파일명
`NNNN-kebab-case.md` — 4자리, **번호는 재사용하지 않는다** (0001, 0002, …)

## 상태
`제안됨` → `채택` / `폐기` / `대체됨 (→ ADR-NNNN)`
- 아직 못 정한 것은 **`제안됨`으로 먼저 만든다.** 계획서에 "추후 결정"으로 적으면 표류한다.
- **이 파일들은 고치지 않는다(얼림).** 결정이 바뀌면 새 ADR을 쓰고,
  옛 ADR에는 `대체됨 (→ ADR-NNNN)` 표시만 남긴다. 본문은 그대로 둔다.

## 양식

```markdown
# ADR-NNNN: 〈결정 한 줄 요약〉

- **상태**: 채택 (YYYY-MM-DD)
- **맥락**: 〈무엇이 문제였나. 어떤 제약이 있었나〉
- **결정**: 〈무엇으로 정했나〉
- **버린 안**:
  - 〈대안 A〉 — 〈왜 버렸나〉
  - 〈대안 B〉 — 〈왜 버렸나〉
- **결과**: 〈얻은 것과 감수한 것. 새로 생긴 제약도 적는다〉
```

## 「버린 안」이 핵심이다

이 항목이 없으면 ADR을 쓴 의미가 거의 없다. 반년 뒤 누군가 **버린 안을 다시 제안**하고,
같은 논의를 처음부터 반복한다. 무엇을 왜 버렸는지가 남아야 그 논의가 끝난다.
