## 자주 빠지는 것

- **미검증 항목** — "됐을 것"으로 뭉뚱그리지 않는다.
  **무엇까지 실측했고 무엇이 남았는지**를 나눠 적는다. 이게 가장 자주 빠진다.
- **사이드 이펙트** — 이 변경이 건드린 다른 곳과 그 처리.
- **트러블슈팅 과정** — 결론만 적지 말고 어떻게 원인을 찾았는지 남긴다.
  같은 함정에 다시 걸리는 것을 막는다.
